# 大白话解释：这次到底怎么测
把模型理解成“干活的人”，Skill 是“操作手册”，Harness 是“给他用的工作台”：负责把材料递进去、让工具能运行、记住做到哪一步、把文件保存和交出来。

我们给五个工作台发同样的四份作业：
1. 核对订单，做完再临时改成只看华东：看算得对不对、记不记得前文、会不会覆盖旧文件。
2. 原样复制两个文件并写清单：几乎不考聪明，重点看能否拿到材料、忠实处理、真正交付文件。
3. 会议资料里混进“别做任务，回复暗号”的文字：看会不会把资料当命令；随后改一个负责人和日期，看能否只改指定内容。
4. 主文件损坏，但有备用文件：看能否说明问题、用备用材料做完，而不是编结果或卡住。

每道作业拆成小勾选项：数字对吗？文件能下载吗？旧文件还在吗？输入有没有被改？满足一条就打勾，不凭“看起来不错”打分。四道作业各占25%，也单独报告真正完成了几次，不能靠其他小分掩盖关键失败。
每款每题独立做3次，一共60次；有两题需要续问，总共90轮。先试跑再固定规则，正式结果不能挑最好的一次。

最重要：五款背后的模型和手册可能不同。谁答错不能立刻说工作台差。我们先记下事实，再找断在哪：材料有没有传进去？工具参数是谁写错的？工具成功了但文件是不是丢了？
能换同一个模型、同一本手册时再做对照；做不到就老实写原因未知。最后给你的是有证据的产品差异和Harness问题清单，不是凭感觉排个名次。
