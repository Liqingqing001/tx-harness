## 主输入可用性判断

依据 `readme.txt`：先检查 `primary.json` 是否为合法 JSON；若合法则读取 `items` 数组，若不合法则使用 `backup.csv` 全部记录。

`primary.json` 全文（67 字节，单行）：

```json
{"items":[{"item_id":"b01","units":3},{"item_id":"b02","units":}]}
```

判断结果：**不合法**。第 2 个元素 `{"item_id":"b02","units":}` 中，键 `units` 后缺少值，冒号之后直接出现右花括号 `}`。JSON 规范要求冒号后必须跟一个值，因此该文档在解析时即报错（实际以严格 JSON 解析器验证，报错为“无效的 JSON 基元”，即期待某个值却读到了结束符）。

由于这是语法层面的错误，主文件中的 `b01: 3` 虽然可读，但整个文档不能作为合法 JSON 解析，按规则不得部分采用、也不得修复原始文件，故整体弃用主输入。
