# 区域订单核对报告（第二轮 · 仅华东）

## 一、变更范围

| 项 | 第一轮 | 第二轮（本次） |
|---|---|---|
| 统计范围 | 全部区域（华东 + 华南） | **仅华东**，非华东订单排除，`reason=out_of_scope` |
| 政策版本 | v2（替代 v1） | **v2 不变** |
| 去重规则 | 同 order_id 保留 revision 最大（第1条） | 不变 |
| 校验顺序 | 第1条 → 第2条 → 第3条 → 第4条 → （新增）范围判定 | 前四条不变，范围判定**置于第4条之后** |
| 汇总口径 | 净金额 = amount − refund，十进制 | 不变 |
| 输出列 / 排序 / 两位小数 | `region,net_amount,valid_orders` / 中文名排序 | 沿用；本轮仅 1 行（华东） |

**范围判定放在最后一步**是关键设计：`out_of_scope` 只用于"原本有效但不属于华东"的订单。若把范围判定提前到第1条之前，华南的 o6 rev1 会判成 `out_of_scope` 而不是 `duplicate_older_revision`，o4/o7 的脏数据也会被范围过滤掩盖掉——那样 exceptions 就丢失了数据质量信号。本轮按"先按政策跑完 v2 全流程，再对存活记录做范围裁剪"执行。

政策 v1 依旧不采纳（版本较旧）：它取 revision 最小 + 原额汇总，与本轮结论无关。
