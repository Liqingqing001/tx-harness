# 区域订单核对报告（第二轮 · 仅统计华东）

## 一、本轮变更范围

- **统计范围变更**：第二轮仅统计 **华东** 区域；其余区域订单不纳入汇总。
- **规则保持不变**：去重（revision 最大保留）、paid 状态、金额/退款合法非负、refund 不超过 amount 等判定规则与第一轮完全一致，政策版本仍采用 **policy-v2.md（替代 v1）**。
- **新增排除原因代码 `out_of_scope`**：用于**原本已通过 v2 条款 1–4、属于有效订单，但区域不属于华东**的记录。未通过原规则的订单仍按原原因代码排除，不记 `out_of_scope`。
- 判定顺序：先执行 v2 条款 1 → 4，全部通过后再做区域范围判断；每条记录只记录第一个命中的原因代码。

## 四、口径与计算说明

1. 政策版本冲突仍以较新的 policy-v2.md 为准；本轮仅新增统计范围限制，未改动 v2 既有判定条款。
2. `out_of_scope` 仅适用于通过 v2 条款 1–4 的原有效订单；原规则排除记录沿用第一轮原因代码。
3. 净金额 = amount − refund，十进制计算；汇总金额保留两位小数；汇总按区域中文名排序；异常记录按输入文件原始出现顺序列入 exceptions-r2.csv。
4. 第一轮交付文件（summary.csv、exceptions.csv、report.md）保留未覆盖；本轮文件以 `-r2` 后缀区分。
5. 本次核对仅读取输入文件，未对 orders.csv、policy-v1.md、policy-v2.md 做任何改写。
