# 正式实验准备记录 · 2026-11-19

[schedule.csv](schedule.csv) 按方案列出 60 次实验、90 轮交互。表中每一行是待执行的试验。执行时按 run_id 保存配置、开始结束时间、提示、输入哈希、现场观察及每轮原件。

正式版 T04 第二轮要求准确列出负责人、截止日期各自的原值和新值。T05 要求分别标明记录数和 units 合计。以上调整适用于今后五款产品的全部正式重复。试跑原件和旧规则可按[校准快照](https://github.com/Liqingqing001/tx-harness/tree/bc266d42bb6637e4bbad060172b253ace1c80ee1)复核。

2026-11-19 已在本地将五款产品的 20 组试跑产物随机编号，按任务和轮次保留 80 份 CSV / Markdown。复评先看编号文件、填判断及理由，再查映射。产品生成的正文可能暴露身份，须记录识别线索。原方案要求个人复评距离初评至少 24 小时，复评及配置核对完成后记录协议冻结提交，再开始正式实验。

每次在产品内建立任务会话时归入“harness对比”项目（如支持），标题注明任务、重复编号、产品；在各自 run_id 下记录实际会话标题、可复核定位方式，以及能否归组。续问保留在同一会话。
