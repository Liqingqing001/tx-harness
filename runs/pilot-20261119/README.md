这里是实际运行后取得的原始交付文件与部分自动检查结果，不是正式重复实验，不构成五款产品排名。每个目录按任务、产品、轮次隔离；原件不修正。尚未取得的文件不会补造。

## 执行条件与局限

- 每题新建会话；T02/T04第二轮沿用本题会话，先归档第一轮再发送固定变更要求。
- Codex、WorkBuddy、DSH通过专属本地输入目录读取文件；元宝上传相同附件。前者增加了输入位置及交付目录说明，任务正文使用任务卡原文。这是产品原生交付路径的试跑，输入通道并未完全受控。
- WorkBuddy可见Hy4 flash、默认权限；DSH可见DeepSeek-V4.1-Flash Low、标准模式、工作区内修改；元宝可见专家模式。模型及内置Skill未完全统一，不能做纯Harness因果排名。
- checks.json是部分自动检查，不能替代全部任务验收。过程日志未完整归档的观察项应为unknown；产物正确不能证明内部执行机制。
- 内容审阅由AI评测者初审，独立第二评审待完成。缺少独立证据的保留文件、输入未改写等声明不能仅凭产品自述判pass。元宝本地上传源未变不等于云端源未变。
- 本目录不含评分器输入给被测产品的记录；参考答案和检验代码没有发送给被测产品。
- 原豆包客户端控制插件发生窗口归属识别错误，尚未发出测试。这是评测环境阻塞，不计产品失败。独立豆包工作入口登录待完成且入口选择待确认。
